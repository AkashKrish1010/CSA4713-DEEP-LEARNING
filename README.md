## Prerequisites

Install required packages:
```bash
pip install numpy pandas scipy scikit-learn tensorflow matplotlib
```

## Running the Experiments

Execute any experiment script directly using Python:
```bash
python EXP_1.py
python EXP_2.py
python EXP_3.py
python EXP_4.py
python EXP_5.py
python EXP_6.py
```
